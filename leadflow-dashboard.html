Connect your live Google Sheet

  1. Open your AI Lead Database sheet, click Share → General access → set to "Anyone with the link" → Viewer.
  2. Copy the Sheet ID from the URL — the long string between /d/ and /edit.
  3. Open this dashboard file in a text editor, find the line near the top of the script that says SHEET_ID = "...", and paste your ID in.
  4. Save and reopen the file (or refresh, if hosted online). It will automatically switch from demo to live data.

Note: this makes the sheet viewable by anyone with the link — fine for internal/demo use. For a client-facing production system, route this through a small backend instead of direct public sheet access.
